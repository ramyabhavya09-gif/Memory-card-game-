
Memory Card Game

A simple and interactive memory card game developed using HTML, CSS, and JavaScript. Players flip cards to find matching pairs and earn points.

## ✨ Features

- 16 cards with 8 matching pairs
- Random card shuffling
- Score tracking system
- Move counter
- New Game button
- Winning message
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎮 How to Play

1. Open the game in your browser.
2. Click on any card to reveal its emoji.
3. Flip another card to find a matching pair.
4. Earn 10 points for every matching pair.
5. Match all pairs to win the game.
6. Click **New Game** to play again.

## 🚀 How to Run

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in your web browser.
